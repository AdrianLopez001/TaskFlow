# TaskFlow: Trilha de Aprendizagem Full Stack

Bem-vindo ao **TaskFlow**! Este repositório foi construído de forma incremental para servir como um guia prático de introdução ao desenvolvimento full-stack com **Java 21 / Spring Boot 3.x** no backend, **Docker** para infraestrutura e **HTML5/CSS3/TypeScript** no frontend.

## 🎯 Objetivo Pedagógico
O principal propósito deste projeto é demonstrar a evolução de uma aplicação:
* Do básico (um endpoint Hello World) até persistência com PostgreSQL.
* Boas práticas de arquitetura limpa (camadas bem definidas: Entity, Repository, DTO, Service, Controller).
* Tratamento robusto de erros e validações.
* Orquestração de containers e isolamento de ambiente com Docker.
* Construção de um frontend dinâmico que evolui do JavaScript Vanilla para o TypeScript moderno.

## 📈 Histórico de Commits (Como estudar este repositório)
Cada commit neste repositório representa uma etapa específica do desenvolvimento. Recomendamos explorar o histórico de commits (`git log`) para ver exatamente quais linhas de código foram adicionadas para cada recurso.
